MAIN MENU SHOWCASE + RADIANT TRANSITION
Based on origin/main commit 937c453.

INSTALL
1. Close Unity.
2. Extract this ZIP into the Unity project root (the folder containing Assets).
3. Reopen Unity and wait until script/import compilation finishes.
4. Open your gameplay scene while NOT in Play Mode.
5. Run: Mining Simulator > UI > Build Showcase Main Menu
6. Save your scene, then enter Play Mode and test PLAY.

WHAT THIS CHANGES
- Uses the supplied showcase background and separate Mining Simulator logo.
- Adds background parallax, organic logo floating, amethyst dust and a geode shockwave.
- Replaces the PLAY handoff with camera dive, rumble, radiant rays, purple-white cover,
  hidden gameplay swap, soft dissolve and HUD fly-in.
- Keeps existing button layout, size, style, labels, OnClick wiring and gameplay logic.

IMPORTANT
- No .unity scene is included. The editor command applies the setup to your open scene.
- Run the builder again safely after future scene edits; it updates named effect objects.
- This package targets the current main branch. Pull/rebase main before applying if your
  local checkout is older than origin/main commit 937c453.
