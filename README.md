# 3D Mining Ore Simulator

Unity 6 mining game with NPC miners, ores, Lucky Blocks, chests and separate world areas.

## Open the project

Open the repository in Unity 6000.5.3f1 and let the Editor import and compile the assets. Gameplay scenes are under `Assets/Scenes/`. Configure game objects in your own scene; ZIP deliveries do not include `SampleScene.unity`.
