# Golem and species boss variants

- Authored `Assets/Prefabs/Monsters/Golem.prefab` and pack clips/materials are retained. Game prefab is `GolemMonster.prefab`, with its own visible `GolemCombat.controller`. Shared `MushroomMonster` behaviour is reused for both species; its new Attack State field is Hammer for Golem. Hammer contact is at normalized time 0.5, sampled against both hand positions in the supplied clip.
- Opt-in setup: `Mining Simulator/Setup/Add Golem and Boss Variants`. First integration adds Golem at weight 25 and changes an original single Mushroom weight to 75. Subsequent runs retain the table, weights, prefab tuning and rewards. Chance weights are normalized (75+25 yields 75%+25%); 0 excludes a species.
- `Assets/GameData/Monsters/MushroomRewards.asset` and `GolemRewards.asset` each contain Boss settings: Enabled, Chance Percent, Minimum Player Level (editable, default 5), Size Increase Percent (35), health/damage/reward multipliers, effect color, combat seconds (120), optional Reward Override. Override supports independent loot tables and level progression. Without override, normal level rarity/scaling and drops are reused, plus boss multipliers.
- Boss probability is checked at actual spawn, not at daily schedule creation. With default level requirement 5 and debug off, level 1-4 get normal monsters. GameManager Gameplay Tuning supports explicit level bypass/forced boss tests; see GameManagerXpBossDebug.md. Boss-size clearance is checked before placing it 4-7m outside the original mine bake. Bosses retain mining-defense targeting and the two-second miner warning. Existing miner/player damage, XP, money popups and loot sounds are reused.
- Boss health bar stays visible and includes a localized BOSS label/countdown. Aura and dissolve rim use the configured effect color.
- Timer starts when the encounter spawns and uses scaled gameplay time. At timeout AI, warning, collisions and damage reception stop; no kill rewards are granted. Meshes dissolve for Dissolve Seconds using per-instance materials, then are destroyed. Death before timeout still plays Down and awards rewards once. Normal Combat Seconds = 0 retains the previous unlimited normal lifetime; set a positive duration to make normal encounters expire too.
- NPC button now uses `Group 3 (1).svg`, preserving root placement, existing miner/coin icons, price logic, hover/click feedback and callbacks.
- Save the modified scene yourself. Delivery ZIP excludes SampleScene.unity per project rules; reapply the two setup menu commands after importing it into another checkout.
- Validation: Unity Editor compilation succeeded. Play Mode verified Hammer and Down clips, boss scale 1.35 and 120-second timer, level-4 boss rejection, expiry damage rejection, disabled motor, dissolve material and automatic cleanup. Shader diagnostics returned no errors. Existing Missing Script warning remains outside this change; full natural daily-wave/combat balancing is not covered by these isolated checks.
