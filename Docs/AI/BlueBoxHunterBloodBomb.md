# Hunter, Blood Tears and Giant Bomb — 2026-10-16

Blue Box now draws up to three distinct unowned upgrades from eight total choices. Already owned upgrades are excluded, including after loading a prior save. If fewer than three unowned upgrades remain, only those remaining choices are shown.

- Hunter: every five player-owned monster kills grants +1 permanent maximum HP, up to +500 bonus HP. This is an additive bonus after other HP multipliers. The remainder toward the next reward and the HP bonus are saved with existing gun-special progression. Existing PlayerStats and health HUD read the bonus through MaxHealth. The ordinary Reset Data flow clears it. Tower-owned kills follow existing player kill-credit rules; despawning without death grants nothing.
- Blood Tears: heals the player for 10% of actual HP removed by player-owned damage to monsters, including owned gun, DOT, splash and other proc damage. Overkill does not add healing. Unattributed/enemy-owned damage grants no life steal. Existing healing-effectiveness modifiers still apply through the canonical Heal method.
- Giant Bomb: each monster has its own counter of received damage events from any source. Every ten events resets that counter and emits an expanding orange ring centered on the monster. Damage is captured at trigger time as 1 + PistolShooting.EffectiveDamage, including the currently selected weapon's level/card bonuses. Each nearby living monster, including the carrier if it survives, is hit once per wave. The tenth hit can be lethal and still emit a wave. Default radius 8m, physical damage; damage type/radius/speed and other tuning are editable. A wave and its synchronous nested procs do not increment bomb counters, preventing direct wave recursion. Existing Bullet Fly interactions remain source-aware.

Settings live in `Assets/GameData/Player/Weapons/BlueGunUpgradeData.asset`. New save fields default to zero/false inside the existing v1 section; the previous five unlocks retain their identities and enum values.

Added semantic Lean Localization keys BLUE_HUNTER, BLUE_BLOOD_TEARS and BLUE_GIANT_BOMB to English.txt and Vietnamese.txt with identical format placeholders. UI descriptions use configured values.

Implementation extends the existing health damage/death boundaries with explicit source attribution. The player upgrade owner manages progression/healing/counts; GiantBombWaves owns a reused wave visual/target snapshot. Disabled/despawned targets are pruned without per-frame scene searches. No scene or input/controller edits.

Validation: connected Editor compiled.
