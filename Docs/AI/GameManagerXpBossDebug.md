# Editable gameplay and boss testing

- ProjectRules now requires editable gameplay values and explicit opt-in testing bypasses, without disabling numerical/data-safety validation. This change does not claim to refactor every old constant in the project.
- GameManager / Mining Gameplay Tuning: Player XP Multiplier scales all AddExperience grants to the player; Mining XP Multiplier scales mining NPC progression before existing upgrade/item boosts. Defaults 1 preserve current behavior; 0 disables gains. Existing per-monster XP rewards remain in MonsterRewardData.
- Boss Minimum Player Level is an editable value (default 5, numerical minimum 1), not a hidden forced level-5 clamp. Ignore Boss Level Requirement permits below-level bosses, Force Boss Spawns bypasses random boss chance. Both default off. Boss Enabled still applies. These switches do not change saved player level.
- Enter Play Mode, enable Ignore Boss Level Requirement, choose Debug Boss Prefab, then use the component context menu Debug / Spawn selected boss now. This uses normal mine-distance, ground/spacing/clearance placement, not unsafe spawning on the player. It is immediate and does not wait for the daily wave. No forecast count is incremented for this manual test.
- Player Data links the original GameData progression defaults (starting level, starting XP, XP Required, XP Requirement Growth). Editing that asset changes defaults/future level-growth, not an existing save's current XP/required threshold. Use the component context menu Player / Read current progress into edit fields, edit Level/Experience/Required Experience, then explicitly Apply edit fields to live progress. Applying uses normal progression saving; merely editing the fields never changes the save. Read/apply menus are Inspector context actions, not game HUD controls.
- Debug switches are explicit authoring settings, not secretly locked by Editor-only conditions. Turn them off before release. Do not call progress Apply while validating unrelated behavior.
- Opt-in setup menu: Mining Simulator / Setup / GameManager XP and Boss Debug. Preserves existing components, placement and assigned references. Save the authored scene yourself; delivery excludes SampleScene.unity.
- Validation: Unity Editor compiled without errors. Verified editable level-2 eligibility, default level rejection and bypass; player XP multipliers 2x/0x/1x yielded 40/40/50 XP from controlled inputs. Play Mode verified boss initialization without a leveled player (scale 1.35) and successful immediate debug spawn through the existing spawner. Debug flags restored off; no player progress Apply action was invoked and no progression save was changed by the isolated XP test.
