AMETHYST GEM HUD
Based on origin/main commit 937c453.

INSTALL
1. Close Unity.
2. Extract this ZIP into the Unity project root (the folder containing Assets).
3. Reopen Unity and wait for script compilation/import to finish.
4. Open your gameplay scene while NOT in Play Mode.
5. Run: Mining Simulator > Setup > Add Or Update Gem HUD
6. Save the scene, enter Play Mode, gain/spend Gems and press the + button.

RESULT
- Matches the supplied purple ore/amethyst capsule sample.
- Uses Assets/Ores/Icons/Items/GemCurrencyIcon.png from the project.
- Shows the number only inside the recessed slot, just like the sample.
- Smooth wallet-driven number rolling, gain/spend punch, breathing gem and gain sparkles.
- The + button has hover/press animation and opens the existing Gem Shop.
- PlayerWallet remains the only Gem/save authority; no extra PlayerPrefs currency is created.

LAYOUT SAFETY
- If Gem HUD already exists, its root position, anchors, pivot and size are preserved.
- Only the visual children inside Gem HUD are rebuilt/styled.
- The command is safe to run again after scene layout changes.

IMPORTANT
- No .unity scene or prefab is included.
- This package targets the current main branch at commit 937c453.
