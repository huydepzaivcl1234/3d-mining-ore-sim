UNITY 6 / URP - RADIAL TRANSITION PREVIEW ONLY

1. Copy Assets/Shaders and Assets/Scripts/Ores/Portal into your Unity project Assets/ folder.
2. Add MiningDynamicRadialMaskTransition to an existing scene GameObject (for example, Mining Portal Gate). Do not add or replace any scene from this ZIP.
3. In Inspector, assign Portal Gate (Transform), Gameplay Camera, and Transition Shader (UI/Mining/DynamicRadialMaskTransition). If Portal Gate is empty, Play Mode looks for a GameObject named Mining Portal Gate; if none exists, the preview starts at Fallback Viewport Center.
4. Assign your Whoosh Clip and Impact Clip. An AudioSource is created on the component GameObject on first preview when absent. Select Use Lava Edge to switch gold to lava. All effect timings and colors can be changed in Inspector.
5. Enter Play Mode, right-click the component title in Inspector, select Test Radial Transition to Underground or Test Radial Transition to Ground. Both actions play the same visual effect. There is NO world change, no portal interaction hookup and no new world in this preview.
6. A full-screen Screen Space Overlay Canvas is created at runtime only if Overlay Image is unassigned. Assign a scene-authored full-stretch UI Image to Overlay Image if you want to inspect or edit the canvas beforehand. The Image must be white and without another graphic material.
7. Overlay UI draws after normal camera post processing in URP: the shader has a visible procedural soft glow, but real Bloom on this overlay requires a suitable renderer feature before post processing.

Includes scripts/shader with .meta GUIDs; no scene or backup files.
