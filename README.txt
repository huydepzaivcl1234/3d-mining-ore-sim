UPGRADE PANEL FULLSCREEN ONLY

1. Giai nen ZIP vao thu muc goc Unity project.
2. Mo scene gameplay trong Unity.
3. Chon menu: Mining Simulator > UI > Make Upgrade Panel Fullscreen
4. Nhan Ctrl+S de tu luu scene.

Cong cu chi sua RectTransform cua object "Upgrade Panel":
- Anchor Min: (0, 0)
- Anchor Max: (1, 1)
- Anchored Position: (0, 0)
- Size Delta: (0, 0)

Khong sua layout con, style, animation, hoac cac panel khac.
Khong chua SampleScene.unity va khong chua bat ky file .unity nao.
